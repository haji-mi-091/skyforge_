## 2026-10-23　可修改的操作绑定

- 新概念（用户批准，契约 §2.10）：`src/data/controls.js` 的 `CONTROL_ACTIONS` 是唯一动作表，33 项动作带分组、标签和默认候选组合；同文件的纯函数负责键码／组合规范化、显示名与组合匹配（完整组合优先于其严格子集）。
- 沿用 `skyforge.settings.v1`，新增 `keyBindings`（动作 id → 候选组合数组）。旧存档缺字段或数据无效时逐项回落到默认；未新增存储键、URL 参数、第三方依赖或全局对象。
- `Input` 新增动作查询并保留原有 `keys`／`pressed` 与鼠标入口以兼容既有检查；`Game`、`Screens`、`Hud` 改为按动作 id 读取键位，主菜单、暂停、帮助面板（`index.html` 的 `data-binding`）与 HUD 提示随当前绑定实时更新。
- 设置新增“键位修改”：点击“修改”→ 键盘擷取单键或组合键 → 鼠标点“确定”才保存；支持取消、单项默认、全部默认，允许多项共用同一绑定，机炮可从鼠标左键改为键盘触发。操作步骤与验证清单见 [../CONTROLS.md](../CONTROLS.md)。

## 2026-10-23　歼-16 机背与尾部模型修整、发动机裸露金属

维护者标出三处机背模型缺陷（座舱后鼓包与凹陷、两垂尾之间的波纹、尾梁与喷口处的块状造型），并要求按照片做出裸露的发动机段。
- 尾部（`src/visual/jet/j16Tail.js`）：z 5.0 起，两发之间的机身由扫描外形过渡到平滑图元的软并集——两个圆形发动机短舱、两侧带凹槽的细尾梁、垂尾基座；|x|>1.3 m 外侧保留原 CAD 蒙皮（垂尾根、腹鳍、平尾轴承都贴合在上面，未改动）。相邻截面沿机身平均，消除波纹；尾锥改为四分之一椭圆收尾；z 8.15 隔框分环，让发动机开口能被切开。
- 座舱后（`src/visual/J16Model.js`）：对座舱后整流罩内部高度做松弛平滑，脊线、外缘、座舱后沿和 z −2.48 接缝固定不动，鼓包旁的凹陷消失。
- 涂装（`J16Skin.js`，银灰迷彩）：发动机段（约垂尾中段到喷口）为深灰钛金属，带接缝环，无漆面和贴花。
- 减速伞舱（按维护者草图与后视照片）：尾梁前段收窄裁剪，尾梁左右各加一片水平"片状梁"（中高位置、从喷口环向后、圆头收尾、保持在喷口鱼鳞片内侧 |x|<0.50 m），左右对称。
- 两垂尾之间机背（维护者第二次圈出）：尾梁改为缓慢收窄，两侧凹槽延后到约 z 6.8（喷口前）才出现，4.75 接缝处的整形过渡由 0.2 m 加长到 0.6 m，去掉 V 形折痕与小台阶。按维护者要求这一步未跑测试，只看了截图和高度剖面。
- 模型三角面 187,971 → 189,911（仍低于 19 万上限），`check-j16-skin` 的固定面数随之更新。
- 验证：多角度环绕检查（尾部 10 个视角含仰视、平尾/方向舵偏转，座舱 5 个视角，白模与迷彩各一套，`work/j16-camo/sheet-*.png`）；24 个 Node 测试（含垂尾根/腹鳍/平尾轴承贴合、尾部碰撞、发动机通道无遮挡）与 7 个歼-16 浏览器检查通过。

## 2026-10-22 – 2026-10-23　三机统一性修复（F-16CM / 歼-16 / 歼-10C）

原为临时交接文档 `docs/HANDOFF_CONSISTENCY_TEMP.md`，工作完成后原文封存为 [2026-10-23-三机统一性修复-交接原文.md](2026-10-23-三机统一性修复-交接原文.md)（内容未改，其中的“待办／未测试”以本页“验证状态”为准）。

### 架构：统一概念 + 机型条目

- 共享代码里按机型 id 写死的判断从 53 处降到 4 处（默认机型 3 处，`Game._createJet` 选外观实现 1 处）。机型差异全部改为配置字段或注册表条目。
- 新增配置字段：
  - `engine.ceilingFade`：升限以上推力衰减，歼-16、歼-10C 设 2000 m。
  - `geometry.hitRadius`：机炮命中半径，歼-16 设 9.5 m。
  - `cannon.trackAmmoMass`：开炮扣弹药质量，三机都开。
  - `systems.seekerLimitedLock`：锁定受导引头限制，歼-16、歼-10C 开。
  - `systems.maxGroundPitchDeg`：地面抬头上限，取实测擦尾角（F-16CM 10°、歼-16 9.5°、歼-10C 12°；`tools/measure-tail-strike.mjs`）。
  - `visual.hangar`：机库、菜单文案和规格栏。
  - `visual.paints`：可选涂装。
  - `penetration.apShells`：哪些弹种查穿甲表。
- 挂载注册表 `LOADOUT_JETS`（`src/data/hangar.js`）：
  - 原先只登记中国机型的 `CN_STORE_JETS` 并入此表，F-16CM 也登记在内。
  - 挂点、预设、校验、存档迁移、武器目录过滤（`storeOffered`）都按表处理。
  - `cnJets.js` 已删除。
- 带机型标记的挂载统一由 `buildTaggedStore` 建模。
- 抛副油箱统一调用 `storeRelease.js` 的 `detachMountedStores`。
- B、J、K 键按配置启用：有减速伞才有 B，有放油速率才有 J，有弹链才有 K。
- 加力尾焰、蒙皮做旧、炮口火光三机各共用一套实现（`F16Exhaust.js`、`skinFinish.js`、`VfxAtlas`）。

### 机型数据（以战雷维基为准）

- **升限**：取各机维基值，F-16CM 15,240 m、歼-16 16,000 m、歼-10C 16,500 m。
- **加力阈值**：三机统一为 1，推满军用推力后才进加力。
  - F-16 原为 0.965，所以 F-16 点加力的时机有变化。
- **起飞襟翼限速**：
  - F-16CM 470 km/h（维基）；着陆襟翼保持 600 km/h，这是维护者的决定。
  - 歼-16 为维基值 600 / 652 km/h。
  - 歼-10C 维基页面没有此项，用编写值 600 / 620 km/h。
- **起飞标定**：三机的起飞襟翼升力按"满加力、不拉杆的离地距离 ≈ 维基起飞滑跑"标定。
- **F-16CM 补齐维基接入**：
  - 新增 `wiki`、`performanceTargets`、`estimates`、RWR 字段。
  - 维基参考机型是战雷的 F-16C Block 50，原有飞行数值保留不变。
- **PL-10 / PL-15 削弱**：射程改为外贸公开基准 × 1.25，即 25 / 181.25 km。

### 武器

### 副油箱

- **歼-10C 新增副油箱**：
  - 1600 L 挂左、右机翼内侧（LI / RI），800 L 挂机腹中线（C），来自维基挂架表。
  - 长度和半径按容量估算。
  - 蒙皮复用共享做旧，另加接缝和加油口。
- **副油箱燃油**（新统一概念）：
  - 燃油量取维基：F-16 合计 3,090 kg，歼-10C 合计 3,320 kg。
  - 飞行时先消耗副油箱燃油；空油箱阻力不变。
  - 抛油箱时扣除空油箱重量加剩余燃油；重生后加满。
  - HUD 续航时间包含副油箱燃油，`T` 遥测显示 `EXT`。
- **歼-16 没有副油箱**：战雷维基里没有这项数据。
