# F-16CM Block 52 液压收放（2026-10-20）

当前实现位于 `src/visual/CadLandingGear.js`，由 `JetModel` 的真实更新路径驱动。
这是按现有 CAD 轮胎与可用轮舱重建的多级液压视觉机构，不是实机液压系统的工程复刻。

- 保留原 CAD 轮胎，轮胎不缩放，收起后仍然渲染，由机身和关闭的舱门遮挡。
- 替换原来不可分段的整块减震支柱，使用定长套筒、活塞杆、轴接头和轮叉。套筒逐级套入，每一级保持重叠。
- 前轮先转平并向后对准舱口，再回缩；前液压杆绕过轮胎前缘，连接轮叉外侧。
- 主轮先向内对准舱口，再垂直回缩。主舱门通过摆臂向外让位，最后回位关闭。
- 去除原 CAD 轮舱内部阻挡新机构的浅顶板和旧支柱安装凸台；主门加宽并增加随门运动的密封边，覆盖加深后的轮舱。
- 前舱门沿用之前修好的向内 134° 闭合方向。

`systems.gear` 仍使用原接口，1 放下、0 收起，收放总时间仍由原有 `gearTime` 驱动。
以收起进度 `r = 1 - gear` 表示：

| 进度 | 行为 |
| --- | --- |
| 0–0.04 | 解锁余量 |
| 0.04–0.30 | 轮组对准，前轮转平 |
| 0.30–0.76 | 液压套筒回缩，轮组入舱 |
| 0.76–0.80 | 入舱安全间隔 |
| 0.80–1.00 | 舱门回位关闭 |

放下时按相反顺序，舱门先完全打开，再伸出轮组。进度采用平滑曲线，中途按 G 反向不会跳变。

验证：

```
node tests/cad-landing-gear.test.mjs
node tests/flight.test.mjs
node tools/check-doors.mjs
node tools/check-gear-game.mjs
```

第一项无需服务器，读取实际 GLB 并调用生产动画代码，在 401 个进度点检查三角面相交：机构/机身、机构/舱门、液压杆/轮胎，并检查定长套筒重叠、轮胎刚体变换和中途反向。
后两项需要先启动 `node server.mjs`，使用真实浏览器检查舱门及可见性。

真实游戏检查会在暂停画面的条件下，用游戏自身的系统更新与 JetModel.sync 执行两轮完整收放，并检查座舱视角切换；不依赖软件 WebGL 的帧率。

交互预览：`/tools/gear-preview.html?view=gear-side&gear=1`，底部可播放或拖动进度。
录制：`node tools/record-hydraulic-gear.mjs [图片输出目录]`。
