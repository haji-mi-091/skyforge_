# 可修改的操作绑定

2026-10-23，用户批准“可修改的操作绑定”提案后实现。影响 F-16CM、歼-16、歼-10C 共用的输入、设置和提示；不改飞机配置、物理、模型或武器参数。

## 使用

1. 在主菜单、机库或暂停页进入“设置”，展开“键位修改”。
2. 点击某项的“修改”，按下一个键或同时按下组合键，例如 `Ctrl + Shift + U`、`W + E`。可以重新按键替换候选内容。
3. 松开按键，用鼠标点击“确定”才保存；按 Enter、Esc、F1 都只会成为候选键位，不会保存、退出或打开说明。

“取消”、关闭设置或折叠列表都会放弃待保存内容。每项有“默认”，列表末尾有“恢复全部默认键位”。修改即保存到本机浏览器，重新打开游戏仍保留，其他设置不受影响。

允许多个动作使用完全相同的绑定，所有满足当前状态和机型能力要求的动作都可响应。完整组合优先于其严格子集：默认 `Alt + F` 只请求起飞襟翼；默认 `Shift + W + A` 仍能同时加油门、下压和向左滚转，因为这些单键互不包含。相反方向绑定在同一键时按既有轴差值自然抵消，不阻止保存。

左右修饰键按 Shift／Control／Alt／Meta 合并识别。机炮的默认鼠标左键及目标切换的 R／侧键组合也可替换为键盘绑定；鼠标移动和滚轮微调仍沿用原输入。系统或浏览器保留的快捷键能否传递给页面，仍由系统和浏览器决定。

## 实现

- `src/data/controls.js` 的 `CONTROL_ACTIONS` 是唯一动作表，现有 33 项，包含分组、标签和默认候选组合；同文件纯函数处理规范化、显示名称及组合匹配。
- 沿用 `skyforge.settings.v1`，增加 `keyBindings`：`{actionId:[[keyCode,...],...]}`。修改单项会替换其候选组合。旧设置没有该字段时逐项使用默认值，无效记录同样恢复默认；不新增存储键、URL 参数或全局对象。
- `Input` 保留原始 `keys`／`pressed` 和鼠标入口以兼容已有检查，新增动作查询供 Game 使用。按下时记录动作，快速按放不会丢失，自动重复不反复触发开关；长按动作读取当前组合。重新映射和失焦清理输入状态。
- `Screens` 通过既有设置回调通知 Game，擷取期间在捕获阶段拦截键盘，候选内容独立于设置存档。实际游戏调用全部按动作查询；暂停／帮助的菜单入口也读取同一绑定。键位说明与 HUD 直接读取同一份数据。
- 设置弹窗排除机库拖曳和滚轮处理，长列表可正常滚动；弹窗沿用原按钮和无边框样式，窄屏按钮换行。

## 验证

纯 Node：`node tests/controls.test.mjs`。浏览器：先启动 `node server.mjs 4173`，再运行 `node tools/check-controls.mjs`。后者使用 `tools/cdp.mjs` 的 `withBrowser`，在独立的测试浏览器内修改设置并于完成后恢复默认，截图和报告写入 `work/controls/`。

覆盖旧设置兼容、33 项全部重复绑定、单键／修饰组合／普通多键组合、Enter／Esc／F1 擷取而不自动保存、取消、默认、保存重载、动态提示、桌面／窄屏布局，以及三架玩家机型的重复开关、长按飞控与油门、键盘机炮、重新绑定的暂停和帮助。机炮检查等待各机型已有起转时间，不绕过武器规则。额外检查组合键按下顺序与快速按放：修饰键后按也能完成组合，未同时按住的快速连续单键不会误组成组合。

本轮已通过 `controls`、`gameplay-controls`、`flight`、`takeoff-trim`、`j16-integration`、`j10c-integration` 六项 Node 检查，以及 `check-controls`、`check-gameplay-controls`、`check-f16-game` 浏览器检查。最后的按键时序修正另用真实浏览器键盘事件复核；截图和三机报告在 `work/controls/`。
