# 通用操作修复与炸弹爆炸

2026-10-21。适用于当前F16与歼16的正式游戏接入。

- 修复降落刹停后无法重新起飞：旧地面刹车逻辑在速度低于0.35 m/s时无条件归零，即使发动机净推力已经大于阻力，仍逐帧清掉正向速度。现在仅在净加速度不大于零时保持停车，不增加虚假起飞推力。
- `O`抛弃全部副油箱。脱离飞机的油箱继承速度并下落；同步减去实际挂载重量和相应外挂阻力，不扣除内油。重复按O不会重复扣重，重生会恢复初始构型。
- `Alt+1`选择已挂武器，`空格`统一锁定／发射／投弹。空空弹先截获再发射；对地武器朝视线与地形的交点释放。机炮仍为鼠标左键。副油箱和瞄准吊舱不进入可发射武器列表。
- F16原先仅展示的对地挂载已进入可发射列表，覆盖普通、制导、集束、燃烧炸弹、空地与反辐射导弹。未公开的飞行、制导和伤害系数是游戏近似值；集束／燃烧弹当前使用通用炸弹弹道与伤害，没有独立子弹药散布或持续燃烧伤害。
- 按真实挂点身份释放，同一类武器优先左右交替、由外向内；中线挂点与单侧剩余挂载仍可正常发射。切换弹种后保持左右交替状态。双联炸弹逐枚释放；火箭弹巢逐枚发射并保留吊舱。只查询发射位置不会消耗挂点。

## 炸弹通用爆炸

`src/visual/BombExplosion.js`实现共享32帧贴图、固定网格层的爆炸动画：初始闪光、膨胀火球、上升灰黑烟云、低空尘云、贴地冲击环和短暂焦痕。普通／制导炸弹通过正式战斗系统的命中事件调用，不再使用导弹的小型爆炸。普通及制导炸弹以地面接触引爆，不再把瞄准点当作空中近炸引信。

规模优先按配置TNT当量、否则按弹重估值进行立方根缩放，并限制最大视觉尺寸；这是游戏效果，不是工程爆炸仿真。水面抑制地面火球和焦痕，使用浅色水雾与波环；空爆不生成贴地尘云、冲击环和焦痕。地面贴图随采样地形法线摆放。单个效果约10秒消退，最多同时保留8组，结束、复位或切场景时释放网格与材质，共享贴图复用。

本次炸弹效果没有新增粒子发射器；其他原有飞机爆炸、火花、损伤烟雾不在此轮替换范围内。当前地面对地瞄准与地图目标类型仍受现有游戏环境限制，没有新增舰船、可毁建筑、独立激光／电视吊舱或投弹落点预测器。

交互预览：[炸弹爆炸](http://127.0.0.1:4173/tools/bomb-preview.html)。可选择100／250／500／1000 kg、地面／水面／空爆，暂停和拖动时间查看各阶段。
