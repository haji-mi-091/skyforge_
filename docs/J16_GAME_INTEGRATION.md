# 歼16游戏接入与用户测试说明

2026-10-21。本次已把歼16注册到正式游戏和机库。模型、活动部件、双发尾焰、机炮贴图闪光、挂载离架和本地战争雷霆音效由实际游戏状态驱动。最终飞行与战斗验收由用户完成。

入口：[歼16机库](http://127.0.0.1:4173/?aircraft=j16)。也可打开游戏，在机型列表选择“歼-16”。机库提供现代制空、维基制空、对地、反辐射四套初始方案，十个挂点支持分别换装和保存。

`src/data/j16.js` 是独立飞行配置：包含质量、惯量、参考面积、升力曲线、阻力、力矩、舵机速率、双发推力、响应和油耗。Wiki未公开的系数已在该文件的 `estimates` 中逐类注明，不能称为战雷原始飞行模型。面积、惯量、气动曲线、发动机响应／高度衰减、炮口速度与游戏伤害均包含项目估值。

极速、爬升、盘旋、滑跑及续航是参考目标，并非本轮实测结果；它们受油量、挂载、高度和当前物理实现影响。页卡中的限制与极限速度也可能使用不同测试条件。最终表现需要用户试飞后调校。现有玩家防自损选项仍适用，因此限值、告警与自动折断并不等价。

## 武器数据与实际接入

`src/data/j16Weapons.js` 有35个挂载目录项目：27个维基基础项目、6个双联挂载变体，以及用户要求的PL-10、PL-15估算配置。维基项目包含PL-8B、PL-12、PL-12A、LD-10、YJ-91A、Kh-29TE、KD-88、KD-88A、YJ-91、YJ-83K、CM-102、两种火箭吊舱、普通／减速炸弹、LS-6系列、GB系列、数据链与YINGS-III吊舱。

已有数据逐项保留弹重、战斗部／TNT当量、制导类别、锁定距离、射程、速度、最大过载、制导时限、IRCCM等；没有公布的项目不会伪称维基数值。完整数值及来源见 `src/data/j16Wiki.js`，运行参数与挂点允许表见 `src/data/j16Weapons.js`，可导出的完整配置在 `work/j16/integration/game-data.json`。

PL-12A采用当前页面的214 kg；[战争雷霆官方更新记录](https://warthunder.com/en/game/changelog/current/1851)也记录了其质量由198改为214 kg及动力修改，因此没有把旧版198 kg用于PL-12A。

| 对比项目 | 维基基础弹 | 本项目自用版估算弹 |
|---|---|---|
| 近距弹 | PL-8B：18 km、Mach 3.5、40 G、制导20 s | PL-10：25 km、Mach 4、60 G、30 s |
| 近距锁定 | 全向3.4 km、后向11 km | 全向8 km、后向15 km；锁定半角90°，仍受载机雷达扫描范围限制 |
| 中远距弹 | PL-12A：120 km、Mach 4、38 G、120 s | PL-15：181.25 km、Mach 5、45 G、180 s |
| 主动雷达导引头 | PL-12A：16 km | PL-15：25 km |

2026-10-22 按用户要求削弱：仅最大射程按“外贸版公开基准 ×1.25”估算自用版，PL-10 为20×1.25=25 km，PL-15 为145×1.25=181.25 km。25%是用户指定的游戏假设，不是已证实的自用／外贸差异。PL-10E 的20 km、105 kg、60 G级参考 [CASI《Air-to-Air Missiles and Guidance Systems》(2020)](https://www.airuniversity.af.edu/Portals/10/CASI/documents/Research/Infrastructure/2020-11-%2030%20Air-to-Air%20Missiles%20and%20Guidance%20Systems.pdf)；PL-15E 的145 km参考 [IISS航展分析(2021-10-08)](https://www.iiss.org/online-analysis/military-balance/2021/10/china-fires-longer-range-aam-at-export-market/)，Mach 5级参考 [IISS速度分析(2022-09-09)](https://www.iiss.org/online-analysis/military-balance/2022/09/analysis-air-to-air-warfare-speed-kills/)。外贸基准采用这些历史公开资料，并不声称已覆盖后续改型。

其余缺乏公开定量依据的参数均是保守游戏估值，不乘1.25：PL-10 全向／尾追锁定12／22→8／15 km、制导45→30 s、助推加速度420→350 m/s²、续航加速度210→180 m/s²、续航时长5→3.5 s、阻力0.000045→0.000060、热焰弹敏感度0.025→0.10、伤害120→90；PL-15 主动导引头40→25 km、过载60→45 G、制导240→180 s、助推5 s×310→4 s×260 m/s²、续航14 s×90→8 s×75 m/s²、阻力0.000028→0.000040、箔条敏感度0.07→0.18、伤害200→150。弹体质量不乘增强倍率，并使发射后的 `projectileMass` 与挂载 `mass` 一致（PL-10 105 kg、PL-15 210 kg）；战斗部字段仍继承基础弹，不作为两型实弹的公开战斗部指标。

这次只调整两机共用的武器条目及对应检查，不改共享制导／飞行算法；既有的固定过载上限、简化探测和干扰模型仍存在。射程字段是发射／累计飞行距离上限，不代表每次发射都能命中该距离的目标。飞机雷达按F16CM复制，当前工作距离100 km，不能把导弹最大射程当作载机雷达范围。备份：`work/pl-missile-balance-20261022/backup/before/`。

本次削弱验证：21/21个Node测试和5/5个浏览器检查通过（gameplay-controls、f16-game、j16-integration、j10c-integration、ai-game）；两机游戏内实际发射PL-10／PL-15，确认使用新射程、过载及质量。`work/pl-missile-balance-20261022/measure.mjs` 使用既有导弹更新器，在1／10 km高度、250 m/s初速进行无制导飞行前后对照，两弹峰值速度及累计飞行距离均下降、无NaN；它不测有效交战射程或命中率。配置快照、测量结果和检查日志均在同一工作目录。

武器已经接入：弹量、重量与外挂阻力变化；当前挂点出弹、速度继承、导轨／弹射／投放；推力段、阻力、重力、速度／G／距离／制导时间限制；红外与主动雷达制导、数据链及干扰弹响应；命中、爆炸伤害和武器名称播报。双联挂载逐枚释放；火箭逐枚发射，吊舱保留。

维基未公开的推力曲线、阻力、抗干扰概率、尺寸补值和游戏伤害均为项目设定。挂点兼容规则按当前十挂点模型和重量限制建立，并非完整复刻战雷的所有挂点限制。

当前地图只有飞机与地形，没有舰船、地面防空单位和可毁建筑实体。对地／反舰武器使用视线落点作为目标，制导炸弹与空地弹使用简化点目标制导；光电／数据链吊舱已计入挂载模型、质量和阻力，尚无独立吊舱画面、激光照射器及完整TV／IR／GNSS操作流程。反辐射弹使用当前雷达目标与辐射状态逻辑。这些属于现有游戏环境的功能边界，不能称为相应武器全部实装系统的复刻。

## 声音、雷达与告警

正式游戏按机型切换音效包。歼16使用 `audio/j16/pack.json` 中已经从本机战争雷霆提取的发动机、加力、座舱和30毫米机炮声音；切回F16恢复其音效包。苏27命名的发动机样本作为声音替代，不标称WS-10B实录。来源、序号和哈希见 `audio/j16/sources.json`。

雷达扫描、锁定、RWR、导弹来袭／跟踪语音及热焰弹／箔条暂时沿用F16CM Block52，包括60／60干扰弹配置；没有声称实现歼16专用雷达或IRST搜索。人声仍服从设置中选定的语音包。

## 操作与用户验收

- `Alt+1` 切换已挂武器；空空弹按原锁定／发射流程使用空格；反辐射弹选择雷达目标。
- 对地／反舰／炸弹／火箭：选择弹种，将视线指向地面或水面，再按空格释放。当前没有投弹落点预测器，普通炸弹、火箭不会自动修正弹道。
- 鼠标左键发射30毫米机炮；`K`循环弹带。150发弹药，持续射击约5秒。
- `G`起落架；`F`着陆襟翼；`Alt+F`起飞襟翼；`H`减速板／地面刹车；`P`座舱盖；`X`座舱视角。
- `B`地面减速伞开关；`J`放油开关；`T`遥测；`ESC`暂停。

建议用户分别验收：[跑道起飞](http://127.0.0.1:4173/?autostart=runway&aircraft=j16)、[无敌机试飞](http://127.0.0.1:4173/?autostart=test&aircraft=j16)、[空战](http://127.0.0.1:4173/?autostart=instant&aircraft=j16)。先检查起降与收放，再比较不同油量／挂载的加速、平飞、爬升、转弯和续航，最后检查射击、锁定、导弹命中、告警与重生。可提供遥测数值及具体构型，继续调校。

## 本轮完成的自检

通过 `node tests/j16-integration.test.mjs`：机型注册、数值完整性、双发推力单位、十挂点、四套方案、弹量／重量消耗及PL增强值。

通过 `node tests/audio-combat.test.mjs`：已有击杀武器名称、语音触发和音频清单回归。

通过 `node tools/check-j16-integration.mjs`：正式页面资源加载、着色器、歼16音效包、机库、原网格交接、双联炸弹分离与火箭吊舱保留；结果在 `work/j16/integration/smoke-check.json`。浏览器检查在加载后暂停，仅调用接入接口；没有执行性能试飞或完整战斗验收。

本轮没有修改白模机体几何；原几何自检仍对应上轮模型。最终飞行、战斗表现及新增任意混挂的动态间隙由用户测试，本报告不宣称这些验收已经通过。
