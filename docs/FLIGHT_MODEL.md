# SKYFORGE 飞行动力学

本文说明 `src/sim/` 里的坐标系、方程、控制律、起降逻辑和验证结果。目标是让工程实现可审计，而不是把“真实感”当作黑箱。

## 1. 坐标系与时间步

- 世界坐标：右手系，`+Y` 向上，`-Z` 为初始北向，`+X` 为东向。
- 机体坐标：`x` 向前（机头），`y` 向右，`z` 向下。
- 姿态用单位四元数表示，积分后归一化；不存欧拉角状态。
- 物理固定步长 **1/120 s**。渲染帧最多补 16 个物理步，剩余时间被截断，避免低帧率下的“死亡螺旋”。
- 渲染使用 120 Hz 状态在视觉层做插值/平滑；`JetModel.sync()` 只读取飞行状态。

主要文件：

| 模块 | 职责 |
| --- | --- |
| `Atmosphere.js` | ISA 温度/密度/声速/动压、校准空速 |
| `Aerodynamics.js` | 升力、阻力、侧力、三轴力矩 |
| `ControlSystem.js` | 电传控制律、包线保护、作动器 |
| `FlightModel.js` | 刚体积分、发动机、燃油、派生数据 |
| `Aircraft.js` | 系统状态、损伤、起降状态机 |
| `math.js` | 四元数、坐标系、插值、投影 |

## 2. 大气

`Atmosphere.js` 使用标准大气分层（对流层到 11 km，平流层到 20/32/47 km），计算：

- 温度 `T(h)`、压力 `p(h)`、密度 `ρ = p / (R T)`；
- 声速 `a = sqrt(γ R T)`；
- 马赫数 `M = V / a`；
- 校准空速（可压缩流公式），HUD 的 IAS 来自这里。

## 3. 气动力

设动压 `q̄ = 0.5 ρ V²`，机翼面积 `S`，平均气动弦 `c`，翼展 `b`。

### 3.1 迎角与侧滑角

由机体速度分量 `(u, v, w)`：

```text
α = atan2(w, max(u, ε))
β = atan2(v, sqrt(u² + w²))
```

低速（`V < 1 m/s`）时置零，避免地面静止时除零/抖动。

### 3.2 升力

```text
CL0 = CL_table(α) + CL_flap · δ_flap
CL  = (CL0 + 0.05 · exp(-2.2 h/b) · smoothstep(CL0)) · f_Mach(M)
L   = q̄ S CL
```

- `CL_table` 是分段线性、带失速的平台曲线；F-16A 的 `CLmax` 约 1.46。
- `f_Mach` 在跨声速区损失升力，超声速后少量恢复。
- 地面效应：上式为 `ΔCL = 0.05 · exp(-2.2 h/b) · smoothstep(CL0)`，同时降低诱导阻力。
- 升力方向由相对气流与机体对称面构造，不直接假设“升力永远沿机体上轴”。

### 3.3 阻力

```text
CD = CD0
   + k CL² (1 - 0.45 · groundEffect)
   + CD_mach(M)
   + CD_stores + CD_gear + CD_flap + CD_brake
   + 0.55 β²
   + 2.2 max(0, |α| - α_limit)²
D = q̄ S CD
```

`CD_mach` 是跨声速峰值的高斯项加超声速增量；跨声速阻力上升是涌现的，不是脚本事件。

### 3.4 侧力与力矩

```text
CY = CYβ β + CYδr δr
Y  = q̄ S CY

Cl = Clβ β + Clp p̂ + Clr r̂ + Clδa δa + Clδr δr
Cm = Cm0 + Cmα α + Cmq q̂ + Cmδe δe
     + Cm_flap δf + Cm_gear δg + Cm_brake δb + Cm_tuck(M)
Cn = Cnβ β + Cnr r̂ + Cnp p̂ + Cnδr δr + Cnδa δa

L = q̄ S b Cl
M = q̄ S c Cm
N = q̄ S b Cn
```

其中 `p̂ = p b / (2V)`、`q̂ = q c / (2V)`、`r̂ = r b / (2V)`。跨声速还有 `Cm_tuck` 高斯项。失速后附加小幅、确定性的机翼摇摆，便于恢复而不是随机发散。

力与力矩都先在机体坐标计算，再通过姿态四元数转到世界坐标；重力单独加在世界坐标的 `-Y`。

## 4. 刚体运动

```text
F_body = F_aero + [T, 0, 0]
F_world = R F_body + [0, -m g, 0]
a = F_world / m
v ← v + a Δt
x ← x + v Δt

ṗ = (L + (Iy - Iz) q r) / Ix
q̇ = (M + (Iz - Ix) r p) / Iy
ṙ = (N + (Ix - Iy) p q) / Iz
```

角速度用四元数微分积分，并归一化。`Ix/Iy/Iz` 是数据表里的滚转/俯仰/偏航惯量。

法向过载由机体 `z` 方向比力计算，供飞控、HUD 和损伤使用：

```text
n = -(F_aero,z + T_z) / (m g)
```

## 5. 发动机与燃油

`F100-PW-220`：

- 干推 76.3 kN，加力 128.9 kN；
- 油门指令 0–1.1；推过军用推力后加力点火（压气机转速约 0.965 起），加力有自己的 0.65 s 迟滞；
- 压气机转速有一阶滞后（spool up/down），不是瞬时推力；
- 推力随密度比 `(ρ/ρ0)^0.82`、冲压 `1 + 0.12M` 和高马赫损失变化；
- 燃油流量分慢车/军用/加力三档，燃油消耗直接改变质量；
- 质量 = 空重 + 燃油 + 弹药 + 挂载。

## 6. 电传飞控

`ControlSystem.js` 不是直接把输入加到舵面，而是“指令 + 反解”：

### 俯仰

- 杆量映射为过载指令 `n_cmd`，中立杆为 1G；
- 正杆上限 +9G，负杆下限 -3G；
- 根据当前动压、升力线斜率、襟翼和 AoA 限制计算可用升力，限制 `n_cmd`；
- 由 `n_cmd` 计算稳态转弯角速度，再用 `(n_cmd - n)` 阻尼；
- 用 `qCmd` 与当前俯仰角速度的误差生成 `qdotCmd`；
- 通过 `Cm` 模型反解升降舵，最后受最大偏度和 1.6 rad/s 作动器速率限制。

### 滚转

- 杆量映射为滚转角速度指令，基础 4.7 rad/s；
- 马赫数和高迎角会降低滚转权限；
- 同样用 `Cl` 反解副翼，受 2.4 rad/s 速率限制。

### 偏航

- 飞行员脚舵 + 侧滑角阻尼，自动消除侧滑；
- 用 `Cn` 反解方向舵，受 1.5 rad/s 速率限制。

这样做的结果是：低速大迎角时可用升力不足，飞控不会凭空产生 9G；高速时同样杆量会产生更大的角加速度，但受结构限制；舵面始终有速率和权限。

## 7. 鼠标视角层

默认相机是 **FPS 式鼠标视角**：鼠标相对移动直接改变 `viewYaw / viewPitch`，相机不再跟随飞机指向。屏幕中央的**圆圈是鼠标光标**，**十字准星是机头指向**；机头自动驾驶追向视角中心。默认指针锁定，`Alt` 呼出系统鼠标，再按一次重新锁定。

```text
viewYaw   += mouseDX × sensitivity
viewPitch -= mouseDY × sensitivity

headingErr = wrap(viewYaw - currentHeading)
pitchErr   = viewPitch - currentPitch
turnLoad   = 1 + min(|headingErr|/60°, 1)^1.15 × 7.7
bankTarget = sign(headingErr) × acos(1 / turnLoad)
loadTarget = turnLoad + pitchErr × 3.0
rollCmd    = PD(bankTarget - currentBank)
pitchCmd   = G-to-stick(loadTarget)
```

- 视角转动是即时的；机头追随受 FBW/AoA/9G 限制，所以会先压坡度再逐渐对准视角中心；
- 转弯过载由视角误差决定，满误差约 8.6G / 83°，对应 Wiki F-16A 约 19.5 s 的盘旋量级；
- 滚转轴目标约 270–280°/s（公开 F-16A 数据量级，WT Wiki 概览表不单列滚转）；
- `A/D` 是直接滚转轴：按住时暂时绕过自动坡度限制，可以连续 360° 滚转/倒飞；
- `W/S` 直接请求 FBW 的可用正/负过载极限（满杆 8.6G / -2.8G，实际由 AoA 和升力限制）；
- 按住 `C` 只停用“机头追视角”，鼠标仍转相机，`W/S/A/D` 直接操纵飞机；松手后恢复追踪；
- 相机位置在飞机后上方沿**视角方向**布置（高度偏移约 4.2 m），所以中央鼠标圆圈指向飞机前方的空域，而不是压在机体上；机头的十字准星再追到这个方向；
- 相机与机头之间没有连线/皮筋，两个标记各自独立。

这不是“鼠标位置直接等于舵面”，也不是“机头瞬移到视角中心”。机头仍受 9G、AoA、滚转速率和能量限制。

### 渲染插值

物理固定 120 Hz，显示可能是 60/120/144/165 Hz。每个固定步开始时把上一帧位置/四元数/速度存入 `prevPose`，渲染帧用剩余时间比例 `alpha` 插值：

```text
pos_render = lerp(prevPos, pos, alpha)
rot_render = slerp(prevRot, rot, alpha)
```

玩家相机、HUD 的机头投影、机炮瞄准线和机体模型使用同一份插值姿态；否则相机会在“没有物理步”的高刷新率帧里前进，而机体不动，产生明显的相对抖动/残影。机身不再接收自身阴影（仍投射阴影），避免跟随飞机的阴影贴图在机身上产生闪烁。

视角相机距离约为 `18 + 0.006 × TAS` 米（250 m/s 时约 19.5 m），比早期版本的 29 m 更近，机体在画面中明显更大。相机沿鼠标视角方向绕机布置，不随飞机滚转；`C` 只是关闭机头追视角，不再切换另一套轨道相机。

## 8. 地面、起飞与着陆

地面状态由 `Aircraft.js` 单独处理，不跑空中气动力积分。

- 接触高度 2.04 m（起落架放下）。
- 地面加速：推力 − 气动阻力 − 滚阻 − 刹车；混凝土滚阻 0.022，草地 0.065。
- 滑跑转向：随速度降低转向权限；A/D 和 Q/E 都能参与。
- 速度 > 40 m/s 才能用俯仰键抬轮，最大 14°；低于 40 m/s 自动回正。
- 升力超过 0.98 倍重力且速度 > 55 m/s 时离地，并给 1.2 s 的起飞保护，避免刚离地就误判撞地。
- 接地判定：AGL ≤ 3.4 m、在跑道上、起落架 > 0.88、下沉率 > -6.2 m/s、坡度 < 12°、俯仰 -4…14°、IAS < 390 km/h。
- 接地时保留水平速度，清零角速度，进入地面滑跑；下沉率 < -4 m/s 会扣 4 HP（重着陆）。
- 跑道外以 >8 m/s 滑跑会判定撞地；跑道/基地外低空撞地或落水触发坠毁。

系统超速（`Aircraft._updateLimits`）：

| 系统 | 限制 | 超限效果 |
| --- | --- | --- |
| 起落架 | 500 km/h | 按超速量持续损伤 |
| 襟翼 | 450 km/h | 持续损伤 |
| 减速板 | 650 km/h | 持续损伤 |
| 机体 | 1480 km/h IAS / M2.05 / +10.8G | 结构损伤/解体 |

## 9. 武器弹道

- 机炮：6000 发/分、初速 1030 m/s、轻微散布、重力、阻力、4 s 寿命；命中按 7 伤害结算。
- AIM-9L：发射后助推 2.4 s，32G 转弯限制，比例导引；目标可以是敌机或热焰弹；9 m 近炸引信。
- 热焰弹有独立速度、寿命和红外特征，导弹会在视场内重新选最可信目标。
- 导弹/机炮都由 `CombatSystem.js` 管理，不依赖渲染帧率。

## 11. 已知简化

- 玩家机不启用自动过载/超速结构自损：正常飞行不会因为拉杆或速度把发动机/机体“飞坏”。战斗损伤、撞地和燃油耗尽仍然有效。AI 仍保留自损逻辑，但当前 AI 不攻击。
- 指针锁定失败时仍使用 `movementX/Y` 相对鼠标；点击画面会再次请求锁定，按 `Alt` 可随时呼出系统鼠标。
- 发动机没有随机故障模型；燃油大于 0 时推力只由转速、空气密度和马赫数决定，燃油耗尽才会停车。

- 气动系数是工程拟合，不是风洞数据或 Gaijin 的专有模型。
- 没有液压、电气、火控雷达、电子战、失速尾旋的完整非线性结构。
- 损伤为分区/概率化模型；没有逐部件失效链。
- 地面只处理地形高度、跑道和基地边界，不做逐建筑碰撞。
- AI 使用同一套 FlightModel，但决策是游戏化行为树，不是真实战术 AI。
- 红外/雷达是游戏化近似；AIM-9L 的抗干扰能力做了玩法平衡。
- 以上限制不影响“同一套物理驱动玩家和 AI”的核心设计。
