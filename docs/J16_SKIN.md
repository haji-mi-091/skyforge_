# 歼16默认服役灰蒙皮

歼16正式游戏、机库及未指定材质的模型预览默认使用 `weathered`。采用用户参考图中的灰色、低可视标识风格；机号61249作为展示编号，不表示对某一实机涂装的逐处测绘复刻。

已加入上／下表面灰色差、独立雷达罩、机身与进气道统一蒙皮、面板接缝与铆钉、检修盖、救援标记、禁止踩踏提示、翼面及垂尾标识、局部淡化与检修油污、尾部积污，以及喷口金属的热变色。玻璃、黑色IRST光学窗、轮胎、起落架、喷口内壁和外部金属保留各自材质，避免全部涂成同一种灰。

`src/visual/J16Skin.js`负责PBR材质及投射。颜色、粗糙度和微小表面起伏共同形成外观；普通蒙皮以哑光漆为主，喷口保留金属反射。磨损以局部污渍和接缝积灰为主，没有整机大面积锈蚀或夸张掉漆。

## 文件与默认值

- `assets/textures/j16/weather.png`：细微漆面变化、污斑与粗糙度参考。
- `assets/textures/j16/top.png`、`bottom.png`：上、下表面面板与标识。
- `assets/textures/j16/left.png`、`right.png`：左右侧面与垂尾；文字分别处理，避免反面镜像字。
- `src/data/j16.js`中的 `visual.paint: 'weathered'`：正式游戏默认值。
- `src/visual/J16Jet.js`：加载蒙皮资源后再显示正式机体；挂架颜色跟随服役灰方案。
- `tools/j16-preview.html`：默认使用服役灰，可选择白模、基础灰、工作区和活动部件分色。

PNG直接供运行时加载，多个歼16实例共享纹理；不在每次生成飞机时重新绘制大图。`buildJ16SkinMaps()`保留可复现的贴图绘制源，`node tools/check-j16-skin.mjs`会重新生成这些PNG；手工修改PNG后若希望保留修改，应先同步调整绘制源，再运行生成工具。

`assets/models/j16/j16-white.glb`继续保留为原始建模／检查资源。新蒙皮由游戏运行时材质和上述PNG组成，没有把自定义投射着色器烘焙进该GLB。因此直接在其他软件中打开白模GLB不会自动显示本次涂装。

## 动画与验证

贴图以机体静止姿态坐标记录，每个活动部件携带自己的投射坐标；襟翼、平尾、方向舵、座舱盖和喷口运动时不会在固定世界贴图下滑动。三个工作区共享同一套机体坐标，避免机头、中段和进气道出现独立贴图接缝。

本轮没有增加机体三角面或修改机体形状，净机体仍为187971个三角面。通过材质默认值、着色器、坐标数值、活动部件贴图稳定性和材质切换检查；已查看整体、顶面、腹部、机头侧面、座舱、进气道、发动机和尾部截图。原模型数据／活动节点检查与正式游戏资源接入检查通过。最终飞行和战斗体验仍由用户进行。
