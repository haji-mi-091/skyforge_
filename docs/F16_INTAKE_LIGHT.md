# F-16CM 轻量进气道

游戏与进气道、起落架预览使用 `assets/models/f16/f16_flight.glb`。原始 `f16_cad.glb` 保留为制作源文件。

旧实现每次加载都会反复提取机身截面，并为候选三角面向整架机身做射线检测。新版将这些工作放入离线构建工具，运行时直接装配预制网格；机身已平滑、前轮舱已开口的标记同时避免重复处理。

保留原进气口外唇及外壳、弯曲内壁、中间翼型支撑、与前轮舱之间的隔板。内壁环向细分从64降至32，删除管状接缝，深处以同一网格内的暗色封口结束，并提前避开主起落架收纳空间。内壁和支撑共用一个简单PBR材质，沿用机身做旧贴图、粗糙度与金属度，深度变暗预先写入顶点颜色。轮舱静态结构按材质合并，内部不再投射阴影。

装配时间仅统计进气道函数，不代表整个游戏加载时间或帧率。报告和检查截图保存在 `work/f16-intake-light/`。

重建资源：`node tools/build-f16-intake.mjs`。昂贵的截面贴合与射线筛选代码仅在 `tools/lib/f16-intake-authoring.mjs` 中，由制作工具使用；游戏模块不导入该文件。导出时只清除未引用的顶点并采用合适的索引宽度，不对机身外壳做抽面。

验证：`tests/f16-intake-light.test.mjs` 将烘焙外壳与原CAD独立比较；`tests/f16-systems.test.mjs` 检查内壁包络、前轮舱隔离、起落架和座舱盖动作；`tests/cad-landing-gear.test.mjs`、`tests/f16-airframe.test.mjs` 检查主起落架、舱门、翼面和挂载；`tools/check-f16-intake.mjs` 与 `tools/check-f16-game.mjs` 检查浏览器显示及正式游戏管线。
